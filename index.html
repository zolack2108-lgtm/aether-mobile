Scan du corps · option

Deux photos en pied (demande à quelqu'un ou mets un minuteur) : de face, bras écartés à l'horizontale, puis de profil. L'appli estime ta carrure et tes proportions sur ton téléphone et les garde dans ton code ; le personnage VRoid du jeu garde la silhouette de son modèle, seule ta taille le change. Les photos ne sont ni gardées ni envoyées.

Une photo seule ne donne pas l'échelle : sans ta taille, l'avatar garde sa taille actuelle et seules les proportions sont estimées.

Installer l'appli sur ton téléphone

  1. Ouvre ce lien sur ton téléphone, dans Safari (iPhone) ou Chrome (Android).
  2. iPhone : touche Partager puis Sur l'écran d'accueil. Android : menu ⋮ puis Ajouter à l'écran d'accueil.
  3. L'icône Aether apparaît avec tes applis : elle s'ouvre directement ici.

Le royaume

  1. Lance Aether sur ton PC (casque VR avec SteamVR, ou ton Quest avec Steam Link).
  2. Dans le menu, ouvre Avatar → Code Aether Mobile et tape ton code.
  3. Dans Amis, ton code profil fait apparaître ton niveau ici.
  4. Rejoindre le monde : un seul serveur pour tout le monde, chat vocal de proximité.

Il y a mille ans, le monde s'est brisé. De ses éclats sont nées des îles, suspendues entre ciel et néant : le royaume d'Aether. En son cœur se dresse la Tour.
